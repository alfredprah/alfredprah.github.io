# Alfred Prah Portfolio

Source for the public Jekyll portfolio and writing site at https://alfredprah.github.io.

## Run locally

Requirements: Ruby, Bundler, and a compatible Jekyll toolchain.

    bundle install
    bundle exec jekyll serve

Open http://127.0.0.1:4000 after the development server starts.

## Repository map

- _posts/ — dated articles
- _layouts/ and _includes/ — shared page structure
- _sass/ and assets/ — styling and browser assets
- img/ — portfolio and article images
- about.html and contact.html — primary profile pages
- _config.yml — site metadata, plugins, and social links
- Gemfile — Ruby dependencies

## Publishing

GitHub Pages builds from the main branch. Review links, personal contact information, and generated output before publishing. Do not commit private documents or credentials; the historical resume PDF is public-facing content and should be updated or removed intentionally.
